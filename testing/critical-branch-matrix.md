Колонка «Сейчас» перечисляет реально существующие проверки, а не утверждает, что ветвь полностью покрыта.

## Точные PostgreSQL-команды baseline

Команды используют только локальные disposable DB, созданные `scripts/dev_db.sh reset-test` и мигрированные `scripts/test.sh`.

```sh
TEST_DATABASE_URL=postgres://tg_ai_bot_dev:tg_ai_bot_dev@127.0.0.1:5433/tg_ai_bot_test \
  cargo test --lib features::new_user_analysis::tests::url_shadow_lock_serializes_same_user_without_blocking_other_users -- --ignored --exact

TEST_DATABASE_URL=postgres://tg_ai_bot_dev:tg_ai_bot_dev@127.0.0.1:5433/tg_ai_bot_test \
  cargo test --lib features::new_user_analysis::tests::cancelled_url_shadow_refresh_releases_its_session_lock -- --ignored --exact

TEST_DATABASE_URL=postgres://tg_ai_bot_dev:tg_ai_bot_dev@127.0.0.1:5433/tg_ai_bot_test \
  cargo test --bin export_url_inventory tests::export_separates_current_flags_from_latest_operator_labels -- --ignored --exact
```

Основные интеграционные проверки транзакций/leases находятся внутри большого ignored-теста `tests/postgres_migrations.rs::clean_test_database_applies_migrations_and_preserves_comment_job_lifecycle`. Отдельные assertions вызываются из него и в инвентаре обычных unit-тестов не считаются отдельными тест-функциями.
