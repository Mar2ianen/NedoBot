# T03 — URL grammar, canonicalization and metamorphic properties

**Репозиторий:** teloxide-antispam / crates/teloxide-url. **Зависимость:** T02. **Тип:** implementation + actual tests, не просто план.

**Перед стартом:** прочитать актуальный `AGENTS.md` и соответствующий production/test код, `testing/references/INVARIANTS.md`, `testing/references/VALIDITY_LEVELS.md`, `testing/references/CORPUS_PRIVACY.md`. Начинать от свежего `main`, не использовать старые PR head. Работать офлайн на синтетике и тестовых БД.

## Generate
- HTTP/HTTPS + Telegram URI grammar; distinct hostname / path / query / fragment / credentials / port. Unicode and IDN, IPv6 literals, punycode, escapes, empty query and duplicate keys, extremely long bounded input, `t.me@evil.invalid`, `t.me.evil.invalid`.
- Mix grammar-constrained valid cases with a separate malformed/byte-mutated V3 lane; report rejection rates.
## Oracles and properties
- Distinct input source never changes canonical URL identity or parser kind.
- Host case folding / default-port normalization only where the URL spec permits; path and query **case** retained, `?a=1&a=2` not silently collapsed.
- Parsing/canonicalization stable and idempotent on supported inputs; lookalike hosts never Telegram internal.
- Same semantic target duplicated across four sources yields one unique evidence target; intentionally different target remains distinct.
## Acceptance
- >=1000 fast cases for principal property group (after profiling), frozen seeds and minimized counterexamples; parser feature matrix green.
- Compare expected properties against independent small oracle/standards, not production normalizer on both sides.
