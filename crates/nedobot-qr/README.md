# nedobot-qr

Ограниченный декодер статических PNG, JPEG и WebP изображений. Библиотека
возвращает QR payload как байты; она не скачивает Telegram media и не решает,
является ли содержимое ссылкой или спамом.

Ограничения по сжатому размеру, ширине/высоте, числу пикселей, QR-кодам и
payload применяются до передачи результата вызывающему коду. Встроенный
пример прогоняет payload через `teloxide-url`, не выводя содержимое ссылок.

Сканер пока не подключён к обработчику Telegram updates: приложению нужна
фоновая очередь с ограничением размера, времени и повторов.
