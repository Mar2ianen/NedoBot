# NedoBot vs ChatKeeperBot: честное сравнение

Референс: публичная документация ChatKeeperBot (`docs.tg.chatkeeper.app`,
разделы Reputation / Statistics / Commands, прочитана 2026-10-04).
ChatKeeper — engagement-SaaS с личным кабинетом; NedoBot — модерация
в первую очередь, с LLM-аудитом и версионированными ML-артефактами.
Сравнение — по возможностям, а не по качеству реализации.

## Репутация

| Возможность | ChatKeeper | NedoBot |
|---|---|---|
| Плюс/минус пользователями за слова в reply | Да, настраиваемые слова, раздельно +/- | Нет |
| Анти-накрутка (интервалы на пользователя и на чат) | Да | Нет |
| Режимы начисления (всем/админы/раздельно, normal/complex/random) | Да | Нет |
| Ручная выдача (`sup_add_*`, администраторы) | Да | Частично: `/notspam`, ручные метки, журнал |
| Сброс (`resetrep`, `resetallrep`) | Да | Нет (метки append-only) |
| Топы (`toprep`/`bottomrep`, по периодам) | Да | Нет |
| Опыт (XP) за активность, бонусы, уровни | Да | Нет |
| Ранги/звания за XP/репутацию | Да | Нет |
| Скоринг риска нового пользователя (LLM + сигналы + ML) | Нет данных | Да: 0–100, evidence, dry-run лестница |
| Обучаемая репутационная голова на разметке ревьюеров | Нет данных (regex/триггеры) | Да: `rep-v1`, supporting-only |
| Внешняя репутация (shared banlist) | Нет данных | Да: CAS + LOLS-зеркало |

Вывод: механики вовлечения (XP/ранги/плюсы) у ChatKeeper богаче;
у NedoBot сильнее антиспам-сторона: обучаемые модели вместо regex,
история решений, безопасный dry-run.

## Статистика чата

| Метрика | ChatKeeper | NedoBot |
|---|---|---|
| DAU/WAU, сообщения по дням/часам | Да, графики | Частично: день/неделя/месяц, без рядов |
| Доля вовлечённых (активные/все) | Да | Нет (нет знаменателя; `getChatMemberCount` не подключён) |
| Теплокарты часы×дни | Да | Нет |
| Когорты удержания (диагональная карта) | Да | Математика есть (`teloxide-statistics`), не подключена |
| Новые/постоянные/активные, карта вовлечения | Да | Нет |
| Первые сообщения (скорость вовлечения) | Да | Косвенно: attraction-когорты после коммента бота |
| Неотвеченные, типы сообщений, правки | Да | Частично: доля реплаев, медиа/ссылки/голосовые |
| Реакции: позитив/негатив/неопределенные | Да (своя таблица) | Да (своя таблица, `Unknown` для кастома) |
| Админы: активность, профили | Да | Нет |
| Триггеры/фильтры: срабатывания | Да | Нет (есть журнал автомодерации, без агрегатов) |
| Рефералы | Да | Нет |
| Токсичность (AI) | Да | Нет (LLM смотрит только аудит новичков) |
| Топы: пишущие / молчуны / реакции | Топ + антиподы по всем осям | `/topmsg`, `/bottommsg`, `/topreact` |
| Карточка пользователя | Да (активность, связи, события) | Да (сообщения, реакции, топ слов, модерация) |
| Выгрузка CSV | Да | Нет |
| Годовая статистика + прогноз | Да | Нет |
| Два диалекта отчёта + локализация | Нет данных | Да: HTML/Rich, ru/en через `StatsStrings` |

## Модерация

| Возможность | ChatKeeper | NedoBot |
|---|---|---|
| mute/ban/warn/kick/undo, составные сроки | Да | Да (ручная модерация по их доке как ориентиру) |
| Капча/верификация новичков | Да | Нет (аудит вместо капчи) |
| Стоп-слова/regex фильтры | Да | Нет (LLM + линейная модель вместо regex) |
| Whitelist | Да | Нет |
| Удаление democracy (`/purge`, `/purge_user`) | Да | Нет |

## Что уже забрано как идеи

- Сентимент реакций (позитив/негатив/неопределенные) — свой таблицы.
- Тихони (`/bottommsg`) — антипод топа.
- Доля реплаев, сообщений на активного.
- Сегменты new/regular/active и когортная математика — в `teloxide-statistics`, ждут подключения.
- Топ-списки по периодам — частично (периодные топы пользователей есть в сводке дня/недели).

## Кандидаты дальше (не обещание)

1. Подключить когорты удержания и DAU/WAU-ряды к месячному отчёту.
2. Знаменатель вовлечённости через `getChatMemberCount`.
3. Админ-статистика (кто отвечает, кто молчит).
4. Агрегаты срабатываний лестницы (сколько review/ban по dry-run).
5. CSV-выгрузка для внешних разборов.
