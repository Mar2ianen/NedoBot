# Independent oracles

- State expected behavior as a property before calling production functions. Do not reuse target production normalizer in expected result.
- Metamorphic: change hostname case vs path case; insert emoji before text entity and adjust UTF-16 offset; reorder source provenance without changing semantic target; duplicate update; retry superseded media; split one alias into two owners.
- For state machines, model *logical end state* per `(instance, chat, user, message)`, effective media generation, active QR evidence, peer identity, last-authoritative label, and shadow projection. Check invariants after each transition when applicable, and convergence after quiescence.
- For ambiguous cases, check stability/no-crash and label V2/V3; don't assert equivalence unless proven.
- Mutation testing should prove tests detect deliberately broken identity/privacy/locking conditions.
